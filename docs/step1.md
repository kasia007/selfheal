# 1단계 — 입력: 경로 하나 (폴더 또는 파일)

**사용자는 경로를 딱 하나만 입력합니다.** 여러 개도, 글롭도 받지 않습니다.
인수로 줘도 되고, 안 주면 물어봅니다.

```
$ python heal.py

📁 검수할 폴더 또는 파일을 입력하세요
   > ./samples/py-index
```

```bash
python heal.py ./samples/py-index              # 폴더 → 폴더 전체가 대상
python heal.py ./samples/py-index/boundary.py  # 파일 → 그 파일만 대상
```

없는 경로나 오타를 넣으면 다시 묻습니다(최대 3회, 그 뒤 exit 3). 비대화형(파이프 · CI)에서
인수가 없으면 물어보지 않고 바로 exit 3 입니다 — 물어보면 CI 가 멈춥니다.

지금은 인수가 없으면 안내 한 줄만 찍고 **exit 3 으로 끝납니다**(`heal.py:154`).
물어보지 않습니다. 그리고 폴더만 받습니다 — `heal.py:97` 이 위치인수 `workdir` 하나를
받고 `heal.py:158` 의 `is_dir()` 검사가 파일을 거부합니다. **이 둘(경로 입력받기 ·
파일 허용)이 1단계의 변경입니다.**

| 입력 | 테스트 실행 범위 | 테스트 루트 | 수정 대상 |
|---|---|---|---|
| **폴더** | 폴더 전체 | 그 폴더 | 스택트레이스가 가리키는 소스 파일 전부 |
| **파일** | **폴더 전체** | **상위로 올라가 언어 마커를 찾은 폴더** | 그 파일 하나 |

**파일을 줘도 테스트는 폴더 전체를 돌립니다.** 파일 이름으로 짝 테스트를 골라내는
방식(`boundary.py` → `test_boundary.py`)은 이름 관례에 기대므로, 관례를 안 따르는
프로젝트에서 테스트를 못 찾아 진단이 망가집니다. 전체를 돌리면 지금 동작과 같아서 새로
만들 것이 없고, 한 파일을 고치다 다른 곳을 망가뜨리는 것도 바로 드러납니다.

대신 **지정 파일과 무관한 실패는 고치지 않은 채 남습니다.** 그것을 결과에 명시합니다 —
`지정 파일 외 실패 2건은 그대로 남았습니다 (폴더를 지정하면 함께 고칩니다)`.

**파일을 받으면 테스트 루트를 따로 찾아야 합니다.** 테스트 통과가 유일한 성공
기준(`heal.py:185 has_tests`)인데 파일 하나에는 테스트도 언어 마커도 없습니다. 그래서
파일의 부모 디렉터리부터 위로 올라가며 `detect_language` 가 보는 마커
(`pyproject.toml` · `package.json` · `go.mod`)를 찾고, 처음 나온 곳을 루트로 씁니다.
루트를 못 찾으면 exit 3 — LLM 을 부르지 않습니다(G7).

**대상 파일 개수에 상한을 두지 않습니다.** 몇 개이고 얼마나 걸리는지는 이후 단계(진단
완료 후 확인 화면)에서 보여 주고 판단은 사용자가 합니다.

## 입력과 스택트레이스가 어긋날 때

입력이 하나여서 어긋남 대부분이 사라집니다. 사용자 목록과 스택트레이스 목록을 맞춰 볼
일이 없습니다. 남는 두 경우만 규칙으로 정합니다.

| 경우 | 처리 |
|---|---|
| 파일을 줬는데 스택트레이스가 **다른 파일**을 가리킴 | **사용자 입력을 따릅니다.** 터진 자리와 원인이 다른 것이 정상이고, 파일을 콕 집어 준 것은 사용자가 원인을 안다는 뜻입니다. 이후 확인 화면에 `스택트레이스: parser.py:40 (지정 파일과 다름)` 을 함께 보여 판단 근거를 남깁니다 |
| 파일을 줬는데 **손댈 수 없는 파일** (테스트 파일 G1 · 매니페스트 G4 · 제외 경로 G3) | **exit 3 으로 거부**합니다. 조용히 무시하면 사용자는 고쳐졌다고 착각합니다. `test_boundary.py 는 수정할 수 없습니다 (G1: 테스트는 성공 기준입니다)` |

의도적으로 **받지 않는 입력** 둘은 그대로입니다 — 수정 방법 힌트(주면 에이전트가 아니라
치환기가 됨), 테스트 수정 권한(주면 LLM 이 테스트를 고쳐 통과시킴, G1).

## 검증

| 무엇 | 어떻게 | 통과 기준 |
|---|---|---|
| 대화형 진입 | `heal.py` (인수 없이) | 경로를 물어보고, 입력하면 다음 단계로 진행 |
| 폴더 입력 | `heal.py ./samples/py-index` | 지금과 동일하게 동작 |
| 파일 입력 | `heal.py ./samples/py-index/boundary.py` | 테스트 루트를 `samples/py-index` 로 잡고 **폴더 전체 테스트**를 돌리되 수정 대상은 그 파일 하나 |
| 파일 입력 — 루트 없음 | 마커가 없는 곳의 파일 | exit 3, LLM 호출 0건 |
| 파일 입력 — G1 위반 | `heal.py ./samples/py-index/tests/test_boundary.py` | exit 3 + G1 사유 표시, 원본 변경 0건 |
